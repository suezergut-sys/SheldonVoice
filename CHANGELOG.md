# История версий

## 0.1.1 — 21.10.2026

- Название под иконкой и заголовок экрана: SheldonVoice. Для иконки использована предоставленная картинка корги без изменений.
- Диалог открывается на последнем сообщении, включая конец длинного ответа. Подгрузка старой истории больше не смещает позицию; возвращение в приложение показывает последние сообщения.
- Идентификатор приложения, ключ подписи и хранилище сессии сохранены для установки обновления поверх версии 0.1.0.
- Добавлены Android Compose-тесты стартовой позиции, подгрузки истории, возврата к последнему сообщению и нового ответа.

## 0.1.0 — 20.10.2026

- Первый Android MVP: Telegram user session через TDLib, телефон/код/2FA, выбор бота.
- Видимая Ogg/Opus-запись, таймер, отмена, отправка voice note и статусы доставки.
- Текстовые ответы и синхронизация диалога, безопасное хранение сессии, JVM-тесты и инструкция установки.
