# Ограничения MVP

- Обновление 0.1.0 → 0.1.1 сохраняет данные при установке поверх старой версии с тем же ключом подписи. Удаление приложения или очистка данных удаляют локальную сессию. Независимо от обновления Telegram может отозвать сессию со своей стороны.

- Один пользовательский аккаунт и один выбранный бот. Нет встроенной настройки OpenClaw/VPS.
- Вход по телефону, коду и 2FA. Регистрация нового аккаунта, email, QR и другие дополнительные сценарии Telegram не реализованы; UI сообщает неподдерживаемое состояние.
- Telegram сам решает способ доставки кода. Получение SMS сторонним клиентом не гарантируется.
- Отправка только голосовых; отображение текста и обозначений прочих сообщений. Нет проигрывания voice-ответов, фото, вложений, inline-клавиатур и ввода обычного текста (кроме /start).
- История ограничена последними 250 сообщениями, до 5 страниц за синхронизацию. Полноценного скролла в старую историю и непрочитанных нет.
- Микрофон только при активном экране; уход в фон/блокировка/поворот отменяют незавершённую запись. Фоновая запись и уведомления отсутствуют.
- Автостарт при открытии с launcher после настройки и согласия на микрофон. После ручной отмены/отправки новая запись запускается кнопкой. Изменения поведения launcher конкретного производителя требуют проверки на устройстве.
- Черновик при ошибке до приёма TDLib живёт до завершения процесса. Принятая TDLib очередь хранится в базе и продолжает работу при повторном запуске. Нет таймаута на sendVoice, чтобы не создавать дубликаты при неопределённом результате: при зависании UI остаётся в Sending до ответа TDLib/перезапуска.
- Аудиокопии принятой очереди хранятся приватно до очистки данных приложения. Автоматическое удаление отложено, чтобы не сломать TDLib retry после перезапуска. Файлы защищены Android storage encryption, но не отдельным шифром приложения.
- Отзыв Telegram-сессии выполняется через настройки устройств Telegram; в приложении нет собственного logout/account switch.
- Системные ошибки Keystore и загрузки JNI требуют очистки данных или исправной сборки; нет отдельного recovery wizard.
- APK использует community AAR официальной TDLib (детали THIRD_PARTY.md). Это не официальный артефакт Telegram. Полная проверка происхождения native binaries и самостоятельная сборка — отдельный шаг для усиленной модели доверия.
- Отладочная сборка не заменяет проверку на реальном телефоне: Telegram-авторизация, кодек производителя, 16 KB page size, доставка OpenClaw и поведение Android 14+ проверяются на устройстве.

# Второй этап

1. Собственная воспроизводимая сборка pinned TDLib из официального upstream, checksum/SBOM и CI на всех ABI; instrumented JNI smoke test.
2. Автоматическое безопасное удаление outbox после подтверждения доставки, учёт квот, зашифрованные черновики и восстановление их метаданных.
3. Проигрывание голосовых ответов, TTS, текстовые сообщения и потоковая индикация ответа OpenClaw.
4. Android instrumentation tests авторизации/разрешений/lifecycle, API 29/34/36 и устройства 16 KB.
5. Пагинация истории, read receipts, расширенные сценарии входа, logout/recovery UI.
6. При необходимости — добровольно включаемые уведомления и отдельный согласованный foreground microphone service с корректными Android 14+ типом/разрешениями и постоянным уведомлением.
7. Release signing, CI и публикация с учётом Telegram API terms/branding и privacy policy.
